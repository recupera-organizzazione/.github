# Organizzazione di ReCUPera
Progetto presentato all'Hackathon OpenTusk 2026 il 01/10/2026.

Applicazione che consente la gestione mediante collegamento al sistema CUP della salute pubblica, con il fine di migliorarne la distribuzione del servizio e ottimizzare i lunghi tempi di attesa.

Mockup funzionante disponibile [qui](https://recupera-sito-completo.vercel.app).
